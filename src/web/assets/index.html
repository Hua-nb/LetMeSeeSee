Let me see see

          
Rust 单文件 + 本地浏览器界面，仅监听 127.0.0.1，全部资源离线内嵌。

          
28 个采集模块：执行四件套（UserAssist/ShimCache/AmCache/BAM）+ Prefetch、文件访问（RecentDocs/OpenSave/ShellBags/回收站）、事件日志（System/应用/网络/TaskScheduler）、Security（登录/进程/账户/暴力破解聚合）、PowerShell 4104、入侵痕迹（自启动/计划任务/服务含 ServiceDll/WMI/账号/USB/IFEO·AppInit·LSA·屏保/Defender/RDP 客户端历史/落盘文件/Sysmon）、现场快照（进程树+网络连接/DNS/hosts）。进程现场已并入「进程树」页展示。

          
仅用于授权范围内的应急响应与安全分析。
